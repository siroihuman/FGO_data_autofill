# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

## 対応項目

- No.
- 基本情報：真名、レアリティ、クラス、性別、身長、体重
- パラメーター：筋力、耐久、敏捷、魔力、幸運、宝具
- クラススキル：任意数、複数形態、宝具情報テンプレート
- 保有スキル：任意数、Skill番号、強化後、強化2回目、宝具情報テンプレート
- 宝具：任意数、カード色、ランク、種別、レンジ、最大捕捉、強化後、強化2回目
- 絆礼装：礼装名、アイコン、フレーバーテキスト、特殊ブロック
- 武器：名称、解説

既存ページのコード全文を「元のコード」へ貼り付けると、自動入力対象だけを更新します。コメント、コメントアウト済みテンプレート、独自注記などの自動入力対象外記述は削除せず保持します。元コードが空欄の場合はページ全体を新規生成します。

## クラスとクラスアイコン

クラスとレアリティからクラスアイコンを自動設定します。基本情報・クラススキル・絆礼装で同じクラス設定を使用します。

- セイバー＝剣
- アーチャー＝弓
- ランサー＝槍
- ライダー＝騎
- キャスター＝術
- アサシン＝殺
- バーサーカー＝狂
- シールダー＝盾
- ルーラー＝裁
- アヴェンジャー＝讐
- ムーンキャンサー＝月
- アルターエゴ＝分
- フォーリナー＝降
- プリテンダー＝詐
- ビースト＝獣

レアリティは★4・★5＝金、★3＝銀、★1・★2＝銅です。

## 身長・体重

数値だけ入力した場合、身長には`cm`、体重には`kg`を自動付与します。すでに単位が入力されている場合は二重付与しません。

## 保有スキルの強化

保有スキルは通常状態に加えて「強化後」「強化2回目」を指定できます。出力順は必ず次の順です。

```text
Skill1
Skill1の強化後
Skill1の強化2回目
Skill2
Skill2の強化後
Skill2の強化2回目
Skill3
Skill3の強化後
Skill3の強化2回目
```

強化2回目をONにした場合は強化後も自動的にONになります。強化後をOFFにした場合は強化2回目もOFFになります。

強化を使用しない場合は、元コードにある対応するコメントアウト済みregionを保持します。対応regionがない場合は標準のコメントアウト済みregionを生成します。

## 宝具の強化

宝具も通常状態に加えて「強化後」「強化2回目」を指定できます。強化2回目をONにすると強化後も自動的にONになり、出力は通常宝具→強化後→強化2回目の順になります。

## 宝具情報テンプレート

クラススキル、保有スキル、強化後スキル、強化2回目スキルでチェックをONにすると、次の記法をフレーバーテキスト／解説欄の先頭へ実際に挿入します。

```text
&font(b,110%){種別：対宝具　レンジ：　最大捕捉：人}&br()&font(b,105%){“”}&br()
```

挿入後は入力欄の通常テキストとして自由に編集できます。出力時に固定テンプレートを追加し直さないため、編集内容が保持され、二重挿入されません。

絆礼装には宝具情報テンプレート機能はありません。

## 絆礼装

絆礼装はクラススキルと同様に、礼装名・アイコン・フレーバーテキスト・特殊ブロック直接指定を入力できます。クラスアイコンは基本情報のクラス・レアリティから自動設定します。

既存コードに`**絆礼装`がある場合はその欄だけを更新します。旧テンプレートなどで絆礼装欄が存在しない場合でも、絆礼装データが入力されていれば武器欄の前へ自動追加します。

## atwikiへの設置

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill@a8310344c5541d8bbb811a88967e1b954d3d9f51/FGO_DataAutofill_atwiki.js)
```

jsDelivrの`@main`キャッシュによる旧版表示を避けるため、最新版の機能一式を含む確定コミットを直接指定しています。

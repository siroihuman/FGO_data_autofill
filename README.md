# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

既存のページコードまたはサーヴァント用テンプレート全文を貼り付け、`**クラススキル`欄だけを入力内容から自動生成します。クラススキル以外の基本情報、パラメーター、保有スキル、宝具、武器などは変更しません。

## 主な機能

- スキルアイコン、表示名、クラス表記、クラスアイコン、フレーバーテキストの自動反映
- 「陣地作成 B+」の登録済みデータを内蔵
- 表示名からランク部分を除き、スキルアイコン名を自動推測
- 任意数のクラススキルに対応
- 複数形態・形態別クラス・形態別見出しに対応
- 説明欄の改行を `&br()` へ自動変換
- 特殊な説明をWiki記法のまま出力可能
- 元コードと反映後コードを左右に表示
- 反映後コード全体、またはクラススキル欄だけをコピー
- 同一タブ内での入力復元（`window.name`を使用）
- 提供されたサーヴァント用テンプレート全文を内蔵

## atwikiへの設置方法

1. 計算機を設置するページをPukiWikiライクモードで作成します。
2. ページの編集権限を「管理者のみ」にします。
3. `v1.0.0/atwiki_page_code.txt` の内容をすべて貼り付けます。
4. ページを保存します。

設置コード：

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill/v1.0.0/FGO_DataAutofill_atwiki.js)
```

`#include_js`を使用するページは、編集権限を必ず「管理者のみ」にしてください。

## 使用方法

1. 既定クラスを選択します。
2. クラススキル名、アイコン、フレーバーテキストを入力します。
3. 特殊形態がある場合は「形態・グループを追加」を押し、見出しとクラスを設定します。
4. サーヴァント編集ページからコード全文をコピーし、「元のコード」へ貼り付けます。
5. 「クラススキルを反映」を押します。
6. 「反映後コードを一括コピー」を押し、サーヴァント編集ページへ貼り戻します。

通常の説明文では、入力欄の改行を自動的に `&br()` へ変換します。`&font(...)`などを含む特殊な記述は「説明欄をWiki記法のまま出力する」を有効にしてください。

## 置換範囲

次の見出しを検索します。

```text
**クラススキル
```

この見出しの次の行から、次に現れる同じ階層の `**` 見出し直前までを置き換えます。そのため、通常テンプレートだけでなく、クラススキル欄の行数や形態数が異なる既存ページにも使用できます。

## ローカル確認

`v1.0.0/FGO_DataAutofill_standalone.html` と `v1.0.0/FGO_DataAutofill_atwiki.js` を同じフォルダーへ置き、HTMLファイルをブラウザーで開きます。

## テスト

Node.jsがある環境では次を実行します。

```bash
node tests/FGO_DataAutofill.test.js
```

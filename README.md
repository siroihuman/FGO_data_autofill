# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

## 対応項目

- No.
- 基本情報：真名、クラス、クラスアイコン、性別、身長、体重
- パラメーター：筋力、耐久、敏捷、魔力、幸運、宝具
- クラススキル：任意数、複数形態、形態別クラス
- 保有スキル：任意数、Skill番号、強化後
- 宝具：任意数、カード色、ランク、種別、レンジ、最大補足、強化後
- 武器：名称、解説

既存ページのコード全文を貼り付けると、対象欄だけを更新します。元コードを空欄にした場合は、入力内容からページ全体を新規生成します。

特殊な構造は、各項目の「特殊ブロック直接指定」へPukiWiki記法を入力することで、そのまま出力できます。真名隠し、特殊な折りたたみ、通常形式では表現できない表にも対応できます。

## atwikiへの設置

設置ページをPukiWikiライクモード、編集権限を「管理者のみ」に設定し、次を貼り付けます。

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill@main/FGO_DataAutofill_atwiki.js)
```

リポジトリには最新版だけを置き、バージョン別ディレクトリは使用しません。設置URLは常に`main`の最新版を読み込みます。

## 使用方法

1. No.と基本情報を入力します。
2. パラメーターを選択します。
3. クラススキル、保有スキル、宝具を必要な数だけ追加します。
4. 武器情報を入力します。
5. 既存ページを更新する場合は、編集コード全文を「元のコード」へ貼り付けます。
6. 「全データを反映」を押します。
7. 「反映後コードを一括コピー」を押し、atwikiの編集ページへ貼り戻します。

入力内容は同じタブでページを再読み込みした場合に復元されます。タブを閉じた後や別タブでは復元されません。

## ローカル確認

`FGO_DataAutofill_standalone.html`と`FGO_DataAutofill_atwiki.js`を同じフォルダーへ置き、HTMLファイルをブラウザーで開きます。

## テスト

```bash
node tests/FGO_DataAutofill.test.js
```

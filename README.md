# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

## 対応項目

- No.
- 基本情報：真名、レアリティ、クラス、性別、身長、体重
- パラメーター：筋力、耐久、敏捷、魔力、幸運、宝具
- クラススキル：任意数、複数形態、見出し、宝具情報テンプレート
- 保有スキル：固定3枠、見出し、強化後、強化後2、再臨差分、特殊入力、宝具情報テンプレート
- 宝具：固定1枠、見出し、強化後、強化後2、再臨差分、特殊入力、カード色、ランク、種別、レンジ、最大捕捉
- 絆礼装：礼装名、アイコン、フレーバーテキスト、特殊ブロック
- 武器：任意数、宝具情報テンプレート、特殊ブロック

既存ページのコード全文を「元のコード」へ貼り付けると、自動入力対象だけを更新します。コメント、コメントアウト済みテンプレート、独自注記などの自動入力対象外記述は削除せず保持します。元コードが空欄の場合はページ全体を新規生成します。

## クラススキル

クラススキルの仕様はver 2.5.0から変更していません。

- 形態・グループ追加：維持
- グループ見出し：維持
- クラススキル追加：維持

## 保有スキル・宝具の固定枠と見出し

保有スキルは3枠固定、宝具は1枠固定です。保有スキル／宝具そのものを増減する追加・削除ボタンはありません。

一方、見出し機能はver 2.6.0で再追加しました。

- 保有スキル：各3枠に「見出し」を設定可能（初期値は`Skill1`～`Skill3`）
- 宝具：任意の「見出し」を設定可能

## 再臨差分

通常・強化後・強化後2のそれぞれで、次の3方式を選択できます。

### なし

再臨差分を出力しません。

### 名称のみ変化（No.044'形式）

保有スキルでは表を複製せず、名称見出しだけをregionで差し替えます。

```text
***Skill1：魔女の棲む森 A
#region(第三再臨後)
***Skill1：創成（支配者） A++
#endregion
|...共通のスキル表...|
```

第二再臨後・第三再臨後を個別に設定できます。

宝具では読み／宝具名だけを変更した同内容の宝具表を`第二再臨後`／`第三再臨後`regionへ出力し、region内に`***第三再臨後&nobold(){}`等の見出しを付けます。

### 再臨段階ごとに別データ（No.034形式）

名称だけでなくアイコン・解説・宝具情報なども変化するケースです。

保有スキルでは第一再臨を通常入力欄として使用し、第二再臨・第三再臨を別データとして入力します。

```text
***Skill3[第一再臨]：未来分岐の観測 A+
|...第一再臨データ...|
***Skill3[第二再臨]：現在脈動の抱擁 B+
|...第二再臨データ...|
***Skill3[第三再臨]：泉より紡ぐ記録 A
|...第三再臨データ...|
```

強化後は`Skill3[第一再臨・強化後]`、強化後2は`Skill3[第一再臨・強化後2]`の形式になります。

宝具でも第一・第二・第三再臨のデータ一式を個別に入力できます。

## 特殊入力（No.024'形式）

通常の再臨差分では表現できない条件付き別形態に使用します。保有スキル・宝具の通常／強化後／強化後2でそれぞれ使用できます。

- 条件／region名
- 見出し
- 別名称・アイコン・解説等のデータ一式

宝具では、たとえば次の形式を出力できます。

```text
#region(close,オーボエの呪言状態の場合)
|...別宝具データ...|
#endregion
```

特殊入力の見出しは任意です。空欄なら宝具では見出しを追加せず、保有スキルでは通常見出しを使用します。

## 保有スキル・宝具の強化

2段階まで対応しています。表記は`強化後`、`強化後2`です。強化後2を有効にすると強化後も有効になります。

## 宝具情報テンプレート

クラススキル、保有スキル、強化後スキル、強化後2スキル、再臨別スキル、特殊入力スキル、武器で使用できます。チェックをONにすると解説欄の先頭へ次の記法を挿入し、その後は自由編集できます。

```text
&font(b,110%){種別：対宝具　レンジ：　最大捕捉：人}&br()&font(b,105%){“”}&br()
```

絆礼装には宝具情報テンプレート機能はありません。

## 武器

「武器を追加」ボタンで任意数の武器を設定できます。各武器は武器名・解説・特殊ブロック直接指定・宝具情報テンプレートを個別に設定できます。

## atwikiへの設置

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill@45855bcaa53afc90a13ff522f7f194befcf40d7f/FGO_DataAutofill_atwiki.js)
```

jsDelivrの`@main`キャッシュによる旧版表示を避けるため、確定コミットを直接指定しています。

## 更新履歴

### ver 2.6.0

- 保有スキル・宝具の見出し機能を再追加
- 保有スキル・宝具そのものの追加・削除機能は引き続き廃止
- No.044'を参考に「名称のみ変化」方式を追加
- 保有スキルの名称のみ変化では表を複製せず、見出しだけregionで差し替える方式へ修正
- 宝具の名称のみ変化では再臨後見出し付きregionへ同内容の宝具表を出力
- No.034を参考に「再臨段階ごとに別データ」方式を追加
- 第一・第二・第三再臨で名称・アイコン・解説等を個別入力可能
- No.024'を参考に任意条件regionの「特殊入力」を追加
- 通常・強化後・強化後2のそれぞれで再臨差分／特殊入力を設定可能
- ver 2.5.0で保存した第二／第三再臨名称差分を「名称のみ変化」へ自動移行
- クラススキルの見出し・グループ追加・スキル追加機能は変更せず維持

### ver 2.5.0

- 保有スキルを3枠固定、宝具を1枠固定へ変更

- クラススキルの機能は変更せず維持
- 第二再臨後／第三再臨後の名称差分を追加

### ver 2.4.0

- 武器を任意数追加できるよう変更
- 各武器に宝具情報テンプレートを追加
- 旧単一武器データの自動移行に対応

### ver 2.3.1

- 2回目の強化表記を`強化後2`へ変更

### ver 2.3.0

- 保有スキル・宝具に2回目の強化を追加
- `最大捕捉`表記を本体処理へ統合

### ver 2.2.0

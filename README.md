# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

## 対応項目

- No.
- 基本情報：真名、レアリティ、クラス、性別、身長、体重
- パラメーター：筋力、耐久、敏捷、魔力、幸運、宝具
- クラススキル：任意数、複数形態、見出し、宝具情報テンプレート
- 保有スキル：固定3枠、強化後、強化後2、第二再臨後／第三再臨後の名称差分、宝具情報テンプレート
- 宝具：固定1枠、強化後、強化後2、第二再臨後／第三再臨後の読み・名称差分、カード色、ランク、種別、レンジ、最大捕捉
- 絆礼装：礼装名、アイコン、フレーバーテキスト、特殊ブロック
- 武器：任意数、宝具情報テンプレート、特殊ブロック

既存ページのコード全文を「元のコード」へ貼り付けると、自動入力対象だけを更新します。コメント、コメントアウト済みテンプレート、独自注記などの自動入力対象外記述は削除せず保持します。元コードが空欄の場合はページ全体を新規生成します。

## クラスとクラスアイコン

クラスとレアリティからクラスアイコンを自動設定します。基本情報・クラススキル・絆礼装で同じクラス設定を使用します。

- セイバー＝剣
- アーチャー＝弓
- ランサー＝槍
- ライダー＝騎
- キャスター＝術
- アサシン＝殺
- バーサーカー＝狂
- シールダー＝盾
- ルーラー＝裁
- アヴェンジャー＝讐
- ムーンキャンサー＝月
- アルターエゴ＝分
- フォーリナー＝降
- プリテンダー＝詐
- ビースト＝獣

レアリティは★4・★5＝金、★3＝銀、★1・★2＝銅です。

## 身長・体重

数値だけ入力した場合、身長には`cm`、体重には`kg`を自動付与します。すでに単位が入力されている場合は二重付与しません。

## 保有スキル・宝具の固定枠

保有スキルは`Skill1`～`Skill3`の3枠固定、宝具は1枠固定です。

保有スキルの「見出し番号」入力、保有スキルの追加・削除、宝具の「小見出し」入力、宝具の追加・削除はありません。クラススキルの見出し・グループ追加・スキル追加機能は従来どおり維持します。

## 再臨段階による名称差分

保有スキルは通常・強化後・強化後2のそれぞれについて、次の名称差分を任意入力できます。

- 第二再臨後の名称
- 第三再臨後の名称

宝具は通常・強化後・強化後2のそれぞれについて、次の差分を任意入力できます。

- 第二再臨後の読み
- 第二再臨後の宝具名
- 第三再臨後の読み
- 第三再臨後の宝具名

差分が入力された場合だけ、該当データ直後へ`第二再臨後`／`第三再臨後`のregionを追加し、名称を差し替えた同内容を出力します。未入力の場合は従来どおりの出力です。

## 保有スキル・宝具の強化

2段階までの強化に対応しています。表記は`強化後`、`強化後2`です。2段階目を有効にすると1段階目も有効になります。

保有スキルは次の順で配置します。

```text
Skill1
Skill1の再臨名称差分（設定時のみ）
Skill1[強化後]
Skill1[強化後]の再臨名称差分（設定時のみ）
Skill1[強化後2]
Skill1[強化後2]の再臨名称差分（設定時のみ）
Skill2
...
```

## 宝具情報テンプレート

クラススキル、保有スキル、強化後スキル、強化後2スキル、武器で使用できます。チェックをONにすると、フレーバーテキスト／解説欄の先頭へ次の記法を実際に挿入します。

```text
&font(b,110%){種別：対宝具　レンジ：　最大捕捉：人}&br()&font(b,105%){“”}&br()
```

挿入後は通常テキストとして自由に編集できます。絆礼装には宝具情報テンプレート機能はありません。

## 武器

「武器を追加」ボタンで任意数の武器を設定できます。各武器は武器名・解説・特殊ブロック直接指定・宝具情報テンプレートを個別に設定できます。

出力例：

```text
**武器
|BGCOLOR(#f5fffa):LEFT:1000|c
|BGCOLOR(#e6e6fa):CENTER:&font(b,110%){【武器１】}|
|&font(b,110%){種別：対宝具　レンジ：　最大捕捉：人}&br()&font(b,105%){“ルビ”}&br()解説|
|BGCOLOR(#f5fffa):LEFT:1000|c
|BGCOLOR(#e6e6fa):CENTER:&font(b,110%){【武器２】}|
|解説|
```

ver 2.3以前の単一`weapon`データは、読み込み時に先頭の武器へ自動移行します。

## atwikiへの設置

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill@c6a4528334cedbd9e7ba3ec1d7d1305f7ebe24bb/FGO_DataAutofill_atwiki.js)
```

jsDelivrの`@main`キャッシュによる旧版表示を避けるため、確定コミットを直接指定しています。

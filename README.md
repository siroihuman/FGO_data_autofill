# FGO データオートフィル for atwiki

atwikiのPukiWikiライクモードで使用する、FGOサーヴァント用データオートフィルです。

## 対応項目

- No.
- 基本情報：真名、レアリティ、クラス、性別、身長、体重、複数人物、注記
- パラメーター：筋力、耐久、敏捷、魔力、幸運、宝具
- クラススキル：任意数、複数形態、見出し、宝具情報テンプレート
- 保有スキル：固定3枠、見出し、強化後、強化後2、再臨差分、特殊入力、宝具情報テンプレート
- 宝具：固定1枠、見出し、強化後、強化後2、再臨差分、特殊入力、カード色、ランク、種別、レンジ、最大捕捉
- 絆礼装：礼装名、効果アイコン、フレーバーテキスト、特殊ブロック
- 武器：任意数、宝具情報テンプレート、特殊ブロック

既存ページのコード全文を「元のコード」へ貼り付けると、自動入力対象だけを更新します。コメント、コメントアウト済みテンプレート、独自注記などの自動入力対象外記述は削除せず保持します。元コードが空欄の場合はページ全体を新規生成します。

## 基本情報

性別・身長・体重は複数組を設定できます。「基本情報を追加」で行を増やし、2行目以降はClass・見出しセルを`~`で継承したWiki表を出力します。

各行には任意の「注記」を設定できます。注記が入力されている場合、性別・身長・体重それぞれの末尾へ同じ`&footnote(...)`を付与します。

```text
|>|>|BGCOLOR(#e6e6fa):Class|>|>|&ref(騎金.png,icon/class,width=30)|>|BGCOLOR(#e6e6fa):性別|男性&footnote(デウカリオン)|>|BGCOLOR(#e6e6fa):身長|179cm&footnote(デウカリオン)|>|BGCOLOR(#e6e6fa):体重|73kg&footnote(デウカリオン)|
|~|~|~|~|~|~|~|~|女性&footnote(ピュラ)|~|~|157cm&footnote(ピュラ)|~|~|45kg&footnote(ピュラ)|
```

既存の単一入力データは自動的に1行目へ移行します。性別欄へ`性別不明`と入力した場合、入力値は保持し、Wiki出力時のみ`-`へ変換します。この変換は複数行すべてに適用されます。

## クラススキル

クラススキルの仕様は変更していません。

- 形態・グループ追加：維持
- グループ見出し：維持
- クラススキル追加：維持

## スキル・絆礼装効果アイコン

クラススキル・保有スキル・強化後・強化後2・再臨差分・特殊入力・絆礼装の効果アイコンは、ファイル名を直接入力する方式ではなく、`icon/skill`ページの画像一覧から選択します。

- `https://w.atwiki.jp/siroi_human/pages/20.html` の一覧を読み込み
- 「アイコンを選択」でポップアップ表示
- ページ上の区分に沿ってアイコンをカテゴリ表示
- 画像をクリックするとそのファイル名を設定
- アイコン名による検索に対応
- 現在選択中のアイコン画像とファイル名を表示
- 選択解除に対応
- 「アイコン一覧を更新」でページ全体を再読み込みせず最新一覧を再取得
- 既存保存データのアイコン名はそのまま維持

## 保有スキル・宝具の固定枠と見出し

保有スキルは3枠固定、宝具は1枠固定です。保有スキル／宝具そのものを増減する追加・削除ボタンはありません。

- 保有スキル：各3枠に「見出し」を設定可能（初期値は`Skill1`～`Skill3`）
- 宝具：任意の「見出し」を設定可能

## 再臨差分

通常・強化後・強化後2のそれぞれで、次の3種類を選択できます。

### なし

再臨差分を出力しません。

### 名称のみ変化

保有スキルでは表を複製せず、名称見出しだけをregionで差し替えます。

第二再臨時の名称が未入力で、第三再臨時だけ名称が変化する場合は、通常名称が第二再臨まで継続します。

```text
***Skill1[第一・第二再臨時]：通常名称
#region(第三再臨時)
***Skill1[第三再臨時]：変更後名称
#endregion
|...共通のスキル表...|
```

第二再臨時に名称が変化し、第三再臨時が未入力の場合は、その名称が第三再臨まで継続します。

```text
***Skill1[第一再臨時]：通常名称
#region(第二・第三再臨時)
***Skill1[第二・第三再臨時]：変更後名称
#endregion
|...共通のスキル表...|
```

第二再臨時と第三再臨時の名称が同一の場合も、`第二・第三再臨時`として1つへまとめます。宝具も同じ継続範囲を使用します。

### 再臨段階ごとに別データ

名称だけでなくアイコン・解説・宝具情報なども変化する場合に使用します。保有スキルでは第一再臨を通常入力欄として使用し、第二再臨・第三再臨を別データとして入力します。

```text
***Skill3[第一再臨時]：第一再臨名称
|...第一再臨データ...|
***Skill3[第二再臨時]：第二再臨名称
|...第二再臨データ...|
***Skill3[第三再臨時]：第三再臨名称
|...第三再臨データ...|
```

途中の再臨段階が未入力の場合は、直前のデータがその段階まで継続するとみなして見出しをまとめます。

- 第二再臨が未入力、第三再臨に差分あり：`第一・第二再臨時`／`第三再臨時`
- 第二再臨に差分あり、第三再臨が未入力：`第一再臨時`／`第二・第三再臨時`
- 第二・第三再臨とも未入力：`第一・第二・第三再臨時`

強化後では条件の後ろへ`・強化後`、強化後2では`・強化後2`を付与します。

## 特殊入力

再臨差分では表現できない条件付き別データに使用します。保有スキル・宝具の通常／強化後／強化後2でそれぞれ使用できます。

特殊入力では「条件」を入力し、その文字列をregion名と見出しの角括弧へ自動挿入します。特殊入力専用の見出し入力欄はありません。

```text
#region(close,オーボエの呪言時)
***Skill1[オーボエの呪言時]：特殊名称
|...特殊データ...|
#endregion
```

## 保有スキル・宝具の強化

2段階まで対応しています。表記は`強化後`、`強化後2`です。強化後2を有効にすると強化後も有効になります。

## 宝具情報テンプレート

クラススキル、保有スキル、強化後スキル、強化後2スキル、再臨別スキル、特殊入力スキル、武器で使用できます。

```text
&font(b,110%){種別：対宝具　レンジ：　最大捕捉：人}&br()&font(b,105%){“”}&br()
```

絆礼装には宝具情報テンプレート機能はありません。

## 武器

「武器を追加」ボタンで任意数の武器を設定できます。各武器は武器名・解説・特殊ブロック直接指定・宝具情報テンプレートを個別に設定できます。

## atwikiへの設置

```text
*FGO データオートフィル

&html(<div id="fgo-data-autofill"></div>)
#include_js(https://cdn.jsdelivr.net/gh/siroihuman/FGO_data_autofill@304e0a9343e7710d29bced9dc1ed209bdfc61406/FGO_DataAutofill_atwiki.js)
```

jsDelivrの`@main`キャッシュによる旧版表示を避けるため、確定コミットを直接指定しています。
